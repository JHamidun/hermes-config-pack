# Коннекторы — 11 каналов

> Числа в строках Smoke — с реального прогона по одной детской научпоп-книге.
> У тебя будут другие; смотри на них как на «канал жив / канал молчит», а не как на норму.
> Free-категории: **(а)** бесплатно абсолютно · **(б)** в рамках уже оплаченного (Claude Max, SerpAPI, ScrapeCreators) · **(в)** нужны новые траты.

---

## 1. `googlenews.py` — Google News RSS

| Параметр | Значение |
|---|---|
| Метод | `GET https://news.google.com/rss/search?q=%22{phrase}%22+{anchors}&hl=ru&gl=RU&ceid=RU:ru` |
| Без ключа | да |
| Лимит | ~100 items/фид → дробить на несколько запросов с разными якорями |
| Smoke | 7 релевантных после дизамбигуации (56 raw без кавычек = 0 про книгу) |
| **Free** | **а** |

**Грабли:**
- Без кавычек и якорей → 100% омоним-шум. Обязателен `q=%22точная+фраза%22+якорь`.
- XML парсить через `feedparser` или `xml.etree`; поле `<link>` — Google-редирект, нужен follow или `source`-атрибут.
- Дублирует агрегаторы типа БезФорматы — дедуп по URL обязателен.

**Нужные креды:** нет.

## 2. `serpapi_connector.py` — SerpAPI (СМИ + Яндекс + точечный поиск)

| Параметр | Значение |
|---|---|
| Метод | `GET https://serpapi.com/search?engine=google&q=...&api_key=SERPAPI_KEY` |
| Engines | `google`, `google_news`, `yandex` (для Яндекс-выдачи) |
| Smoke | 21 уникальный результат (СМИ + агрегаторы) |
| **Free** | **б** (SerpAPI оплачен, кредиты тратятся) |

**Грабли:**
- Кредиты: 1 запрос = 1 кредит, не расходовать на тест-прогоны без `limit`.
- Яндекс-engine даёт рунет-СМИ, которых нет в Google News. Использовать точечно.
- `organic_results` + `news_results` — оба парсить.

**Нужные креды:** `SERPAPI_KEY`.

## 3. `vk.py` — ВКонтакте (через SerpAPI `site:vk.com`)

| Параметр | Значение |
|---|---|
| Метод | `SerpAPI engine=google q="{phrase} автор" site:vk.com` (5 стр = 50 ссылок) |
| Без VK-токена | да (обход VK ID OAuth / бизнес-верификации) |
| Smoke | **49 raw**, 24 живых поста после дедупа |
| Ценность | Библиотеки, книжные блогеры, посты иллюстратора — живые читательские отзывы |
| **Free** | **а** (SerpAPI кредиты; парсинг `site:` бесплатнее обычного поиска) |

**Грабли:**
- Сниппеты ~150 симв, лайки недоступны без VK API-токена. Для `_engagement` = 0 пока нет токена.
- VK API (нативный) требует пользовательский OAuth токен и с 01.03.2026 — бизнес-верификацию. Резервный вариант — в `book.yaml` секция `vk_token`.
- Посты групп vs. личные стены — URL-паттерн `vk.com/wall-XXXX_YYY` (группа) vs `vk.com/id…`.

**Нужные креды:** `SERPAPI_KEY`. Опционально: `VK_TOKEN` (для лайков).

## 4. `dzen.py` — Яндекс Дзен (через SerpAPI `site:dzen.ru`)

| Параметр | Значение |
|---|---|
| Метод | `SerpAPI engine=google q="{phrase} автор" site:dzen.ru` |
| Smoke | **48 raw** (DISCOVER_LOG: 4 релевантных), много мусора от рекламных сетей |
| Ценность | Региональные СМИ/блогеры (Ведомости НСО и т.д.) |
| **Free** | **а** (SerpAPI кредиты) |

**Грабли:**
- Дзен за Яндекс-SSO: прямой HTTP → 302 редирект. Сниппеты из SerpAPI достаточны для дизамбигуации.
- Рекламные футеры Дзена индексируются Google («подборка материалов», «мягкие игрушки», «лучшие книги» — 1 слово совпало) → opus отсекает. Без opus precision ~8%.
- Полный текст статьи: нужен Playwright с сессией (опционально, `dzen.py` его не делает).

**Нужные креды:** `SERPAPI_KEY`.

## 5. `telegram.py` — Telegram (tg_client + msg-views)

| Параметр | Значение |
|---|---|
| Метод | `python tg_client.py search-global "{phrase}" --limit 30` → затем `msg-views` на найденных message_id |
| Smoke | 3–7 упоминаний (TG-каналы издательств + книжные каналы) |
| Уникальность | `views` / `forwards` / `reactions` прямо из TG API — у Медиалогии этого нет |
| **Free** | **а** (Telethon, без ключей) |

**Грабли:**
- Telethon архивирован (фев-2026) — работает, но долгосрочный риск. FloodWait при агрессивных прогонах.
- `search-global` ищет только по публичным каналам. Личные чаты/закрытые группы недоступны.
- `msg-views` требует отдельный вызов на каждый message_id — батчить через `get_messages(ids=[...])`.
- Аккаунт Telethon: `~/.hermes/ccpack/tools/tg_client.py`. Сессия `.session` должна быть активна.

**Нужные креды:** своя Telethon-сессия (`api_id`/`api_hash` с my.telegram.org, бесплатно).

## 6. `rsshub_tg.py` — RSSHub (TG-каналы издательства и автора)

| Параметр | Значение |
|---|---|
| Метод | GET `{RSSHUB_BASE_URL}/telegram/channel/{channel}` — по умолчанию публичный `https://rsshub.app` |
| Smoke | 7 упоминаний книги из канала издательства |
| Ценность | Собственные каналы издательства — первичные анонсы, пресс-материалы |
| **Free** | **а** (публичный инстанс бесплатен; свой — свой же хостинг) |

**Грабли:**
- Свой RSSHub обычно слушает 1200 на localhost и наружу закрыт. Тогда задай `RSSHUB_SSH_HOST=<хост из ~/.ssh/config>` — коннектор пойдёт через `ssh <host> curl`. Не задан — идёт прямым HTTP на `RSSHUB_BASE_URL`.
- RSSHub TG-коннектор иногда отдаёт HTML Telegram Preview вместо RSS при ротации IP — retry 2–3 раза.
- Список каналов для мониторинга задаётся в `book.yaml → telegram_channels`.

**Нужные креды:** нет (публичный RSSHub) либо свой инстанс + доступ к нему.

## 7. `livelib.py` — LiveLib (читательские рейтинги + рецензии)

| Параметр | Значение |
|---|---|
| Метод | `GET https://www.livelib.ru/find/books/{isbn_or_title}` → JSON-LD schema.org из HTML |
| Smoke | 1 книга: рейтинг **5.0**, 1 оценка, 1 рецензия (поиск по ISBN из `book.yaml`) |
| Уникальность | Читательский рейтинг + полный текст рецензий — у Медиалогии нет |
| **Free** | **а** |

**Грабли:**
- Кодировка: charset=utf-8 в `<meta>`, но JSON-LD бывает сериализован в cp1251 → декодировать как `bytes.decode('cp1251')`.
- Для новых книг (< 2 мес) база пуста или 1 оценка — это стадия жизни книги, не дефект.
- Поиск по ISBN надёжнее, чем по названию (омоним). ISBN брать из `book.yaml`.
- Уважать robots.txt: пауза 3–5 с между запросами.

**Нужные креды:** нет.

## 8. `marketplace_stores.py` — Маркетплейсы/книжные магазины

| Параметр | Значение |
|---|---|
| Метод | `SerpAPI site:chitai-gorod.ru site:ozon.ru "ISBN или название"` → сниппеты с ценой/наличием/отзывами |
| Smoke | часть магазинов отдаёт отзывы и цену; Ozon/WB/ЛитРес блокируют (307/498/403) |
| Ценность | Отзывы покупателей (другой слой, чем LiveLib), цена/наличие как косвенный спрос |
| **Free** | **а** (SerpAPI кредиты) |

**Грабли:**
- Ozon, WB, Book24 блокируют прямой HTTP → только через SerpAPI-сниппеты.
- Отзывы только в сниппете (~150 симв). Для полного текста нужен ScrapeCreators или Playwright.
- Книга `print-only` — ЛитРес/BookMate дадут 403 или пустой результат.

**Нужные креды:** `SERPAPI_KEY`.

## 9. `youtube.py` — YouTube (Data API + ScrapeCreators)

| Параметр | Значение |
|---|---|
| Метод (A) | YouTube Data API v3: `GET https://www.googleapis.com/youtube/v3/search?q="фраза"&key=YT_API_KEY&part=snippet` |
| Метод (B) | ScrapeCreators `/v1/youtube/search?query=...` (8 кредитов/вызов) |
| Smoke | **28 raw** (Data API ключ не активирован — нужно включить YouTube Data API v3 в Google Cloud Console); ScrapeCreators работает (осталось 24 452 кред) |
| **Free** | **б** (ScrapeCreators кредиты; YT Data API 10 000 unit/день бесплатно) |

**Грабли:**
- **YouTube Data API v3 требует явного включения** в Google Cloud Console → Библиотека APIs → включить «YouTube Data API v3» для проекта с `YT_API_KEY`.
- ScrapeCreators YT: 1 запрос = 8 кредитов, лимит ~3000 запросов на остаток. Не спамить.
- Для новых книг буктьюб пустой — нормально. Проверять раз в 1–2 месяца.

**Нужные креды:** `YT_API_KEY` (включить в GCP Console) или `SCRAPECREATORS_API_KEY`.

## 10. `scrapecreators.py` — Instagram / TikTok / Reddit

| Параметр | Значение |
|---|---|
| Метод | `POST https://api.scrapecreators.com/v1/{instagram,tiktok,reddit}/search` |
| Smoke | **19 raw** (Instagram + Reddit; TikTok пустой для книги) |
| Важно | ScrapeCreators **НЕ поддерживает VK / Telegram / Дзен** (только западные платформы) |
| **Free** | **б** (кредиты оплачены, баланс ~25К; новые кредиты — $10/5000) |

**Грабли:**
- VK/TG/Дзен — НЕ через ScrapeCreators, несмотря на FAQ. Проверено по docs.scrapecreators.com.
- Instagram-поиск по хэштегу даёт посты; `q="название_книги"` в TikTok малоэффективен без распространённого хэштега.
- Кредиты: Instagram ~5 кред/10 постов, Reddit ~3 кред/вызов. Контролировать через `/v1/account/credits`.

**Нужные креды:** `SCRAPECREATORS_API_KEY`.

## 11. `wordstat.py` — Яндекс Вордстат (спрос на книгу)

| Параметр | Значение |
|---|---|
| Метод | `POST wordstat.yandex.ru/wordstat/api/getTable` (internal API через куки браузера) |
| Smoke | **partial** — работает только при наличии куки залогиненного сеанса Яндекса |
| Ценность | Месячный поисковый спрос «название книги» / «автор книга» — индикатор интереса |
| **Free** | **б** (нужна кука `YANDEX_WORDSTAT_COOKIE` от активного Яндекс-аккаунта) |

**Грабли:**
- Прямой Wordstat API заблокирован (error 58) → только internal API через куку залогиненного браузера.
- Кука протухает. Обновление: `wordstat_browser_snippet.js` (из seo-machine) через Playwright.
- Оценочные объёмы завышены 5–10× — брать как относительный индекс, не абсолют.
- **Яндекс Suggest** (`suggest.yandex.ru/suggest-ya.cgi?v=4&part=...`) работает без логина — расширяет якоря-дизамбигуаторы реальными поисковыми хвостами.

**Нужные креды:** `YANDEX_WORDSTAT_COOKIE` (куки залогиненного браузера, обновлять ~2 нед).
