# Дизамбигуация омонимов — главный урок

> Проблема вылезла в первый же день обкатки. Без дизамбигуации precision системы = 0–8%.
> С двухслойной защитой = 80–100%. Цифры ниже — с реального прогона по книге,
> название которой совпадало с названием государственного просветительского проекта.

---

## Проблема: название книги — не уникальный ключ

Разбираемый случай: детский научпоп-атлас про народы региона. Название почти дословно
совпало с тремя другими сущностями:

| Сущность-омоним | Почему шумит |
|---|---|
| Государственный «интерактивный атлас» на ту же тему | Веб-портал, регулярно публикуется в региональных СМИ |
| Региональные атласы соседних областей и «атлас народов России» | Похожее название без автора и издательства |
| Рекламный футер новостной ленты | «лучшие книги», «атлас» — одно слово совпало, а страница индексируется |

Запрос без кавычек (`атлас народов <регион>`) → **0% релевантности**, 100% омоним-шум.
Подставь сюда свою книгу: у художественной прозы это обычно экранизация, у бизнес-книги —
одноимённый курс, у биографии — однофамильцы.

---

## Двухслойная защита

### Слой 1 — на уровне запроса

**Точная фраза в кавычках** + **якоря-дизамбигуаторы** + **минус-слова**.

В `book.yaml`:
```yaml
title: "<Название книги>"
authors:
  - "<Фамилия автора>"
  - "<Фамилия иллюстратора>"
anchors:
  - "<подзаголовок>"
  - "<Издательство>"
  - "<издательство в другом написании>"
  - "<ISBN>"
exclude:
  - "интерактивный атлас коренных малочисленных"   # твой госпроект-омоним
  - "геоинформационный портал"
  - "<омоним из соседнего региона>"
  - "<похожее название другой книги>"
```

Запрос для Google News / SerpAPI строится как:
```
"<Название книги>" (<Фамилия автора> OR "<Издательство>" OR "<подзаголовок>")
```

Результат на разбираемом случае: с якорями 35 кандидатов вместо 56+ сырых
(ушёл явный госпроект-шум).

### Слой 2 — opus-агент `is_target_book`

Промпт: `scripts/classify/disambiguate_prompt.md`.  
Вход: `{title, snippet, source, url}` батчем, JSON-schema.  
Выход: `{id, is_target_book: bool, role, genre, cite}`.

```
Из 35 кандидатов:
  - 10 отброшены opus (госпроект ×3, Липецкий атлас ×1, рекламный Дзен ×4, слабый контекст ×2)
  - 25 подтверждены как целевые
```

Без opus из 35 «прошедших запрос» — 25 правильных (71%). С opus — 25 из 25 (100%).

## Как настраивать `book.yaml` для новой книги

### Шаг 1: найти омонимы

1. Поиск по названию без кавычек в Google и Яндексе → посмотреть, что шумит.
2. Яндекс Suggest (`suggest.yandex.ru/suggest-ya.cgi?v=4&part={название}`) → хвосты запросов, которые показывают реальный контекст путаницы.
3. Проверить: есть ли госпроект, нацпроект, топоним или одноимённый фильм/игра с тем же названием.

### Шаг 2: заполнить anchors и exclude

```yaml
# anchors: слова/фразы, хотя бы одно из которых ДОЛЖНО быть рядом с названием
# (OR-логика в запросе)
anchors:
  - "ФИО автора"
  - "издательство"
  - "подзаголовок"
  - "ISBN без дефисов"

# exclude: минус-слова — если есть, сниппет/заголовок отбрасывается ещё на уровне запроса
exclude:
  - "нацпроект"
  - "государственная программа"
  - "интерактивный портал"
```

### Шаг 3: проверить без LLM

```bash
python monitor.py run config/mybook.yaml --llm none
```

Просмотреть `out/to_classify.json` — если шума много, дополнить `exclude`.

### Шаг 4: прогнать opus

После `collect` запустить Task opus на `to_classify.json`. Проверить отброшенные: если opus отсеял > 30% — нужно уточнить `anchors` (слой 1 пропускает лишнее).

## Реальный результат PoC

```
Исходные кандидаты (Google News без кавычек):    56   (0% про книгу)
После запроса с кавычками + якорями:             35   (71% про книгу)
После opus is_target_book:                       25   (100% про книгу)

Фильтрация по слоям:
  Слой 1 убрал:  21 (госпроект + рекламный шум)
  Слой 2 убрал:  10 (пограничные кейсы: слабый контекст, омоним в 1 предложении)
```

**Вывод:** двухслойная защита обязательна. Запросы без кавычек+якорей использовать НЕЛЬЗЯ.

## Типичные омонимы по типу книги

| Тип книги | Частый омоним | Рекомендуемый якорь |
|---|---|---|
| Детская / научпоп по теме | Госпроект / нацпроект с похожим названием | Имя автора + издательство |
| Биография | Другие люди с той же фамилией | Полное имя + год + «книга» |
| Бизнес / self-help | Тренинги, курсы, блоги с похожим названием | Издательство + ISBN |
| История / география | Топонимы, исторические события | Подзаголовок или серия |
| Художественная проза | Одноимённый фильм, сериал, игра | Автор + «роман» / «повесть» |
